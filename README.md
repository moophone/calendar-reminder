# 日历提醒工具 v2.0

一款桌面端日历 / 倒计时提醒软件，用 **PyQt6** 构建，主打"把任意格式的待办信息（自然语言、Markdown 赛事清单、聊天粘贴文本）一键变成带截止日和倒计时的日历事项"。

## 为什么做这个

备考期间需要同时跟踪几十个赛事 / 报名截止日 / 投稿 deadline，散落在各群通知和公告里。手抄进系统日历太慢，纯文本备忘又没有倒计时。于是写了一个能"粘贴一段话 → 自动识别日期 → 生成倒计时提醒"的工具，给自己也是给同类的同学用。

## 核心特性

- **自然语言解析**：粘贴一段通知，自动抽取日期 / 时间 / 重复 / 倒计时，按"标题 + 截止日 + 备注"结构化成事项
- **结构化文档识别**：Markdown 标题节（`### 1. 某赛事` + `- **截止时间**：10月16日`）会被切成每节一件事，属性行并入备注而非碎成独立待办
- **AI 兜底解析**：规则解析不出来的句子，可选用本地 Qwen 小模型补抽，结果与规则侧做句子配对、择优合并（含垃圾门：属性行 / 残句标题自动丢弃）
- **倒计时面板**：天 / 时 / 分 / 秒实时刷新，临近事项自动置顶
- **月历视图 + 三栏主窗**：左侧月历、中间事项列表、右侧详情
- **5 套主题**：浅色 / 深色 / 跟随系统 / 高对比等
- **开机自启 + 单实例守卫**：双击 exe 唤起已有实例而非重复开
- **数据本地存储**：SQLite，无网络依赖
- **打包成单文件 exe**：PyInstaller `--onefile`，开箱即用

## 技术栈

| 层 | 选型 |
|----|------|
| UI 框架 | PyQt6（仅依赖，无 Web 技术） |
| 解析管线 | 纯 Python 规则解析 + 可选本地 LLM 兜底 |
| 本地模型 | Qwen3-1.7B-Q8_0（llama.cpp 推理，1.8GB） |
| 存储 | SQLite（单文件，`data/calendar.db`） |
| 打包 | PyInstaller 6.x `--onefile --windowed` |
| 测试 | unittest，79 条全绿 |

## 运行

### 开发态

```bash
pip install PyQt6
python main.py
```

（可选）启用本地 AI 兜底解析：把 `Qwen3-1.7B-Q8_0.gguf` 放到 `models/`，`llama-server.exe` 放到 `llama/`（两者均不入 git，见 `.gitignore`）。

### 打包 exe

```bash
python -m PyInstaller --onefile --windowed --name 日历提醒 --icon app.ico main.py
```

## 解析能力速览（用真实赛事清单验证）

粘贴一份 Markdown 格式的"10 月可报名赛事清单"（10 个赛事、含大类标题 / 属性行 / 元叙述），解析结果：

| 期望 | 实际 |
|------|------|
| 10 个赛事事项 | ✅ 10 个，零垃圾行 |
| 属性行（费用 / 方向 / 含金量） | ✅ 并入所属赛事备注，不独立成事件 |
| "10月内截止" 这类大类标题 | ✅ 不误解析成 2027-10-01 |
| "次年3月" 这类只有月份的表达 | ✅ 标存疑，暂定 2027-03-01 |
| `24:00` 边界时间 | ✅ 归一为当天 23:59 |

详见 `tests/test_p0.py::TestParseStructured`。
